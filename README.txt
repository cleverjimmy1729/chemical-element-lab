元素之间 · 三维化学实验室

交付文件：上一级目录的「元素之间·三维化学实验室.html」。
在支持 WebGL 的现代浏览器中双击打开。无需联网、安装或启动服务器。
HTML 内嵌 Three.js、全部样式与脚本；CSP 禁止运行时网络连接。

使用：
1. 从常用元素或完整周期表中选择元素，点击地面或方块表面放置。
2. Esc 退出放置；选择后拖动方块，或在右侧输入中心 X/Y/Z 坐标。
3. 点击开始。对需要启动条件的反应，选择方块再点击点火 / 加热。
4. 右键拖动旋转视角，滚轮缩放，F 聚焦，空格暂停，Delete 删除。
5. 保存布局 / 载入使用离线 JSON；保存的是初始单质布局，不是反应快照。

默认：25°C，干燥空气，1 atm。每块初始体积 1 m³。
气体和液体在开始后按近似模型扩散 / 铺展；勾选约束范围可保留立方控制区。
固体中心固定，不施加爆炸位移。最多160块，可同时放置全部118种元素。
磷可以选择白磷或红磷；碳为石墨；硫为斜方硫。

科学范围：
118 种元素可选，82 条常见反应路径。使用启动条件、接触面积、元素原子
物质的量和参考反应热。速率、局部热容量、界面温度及视觉效果为教学近似。
没有匹配规则的组合会明确标注反应库未覆盖，不能据此断言不反应。
不计算 CFD、压力波、剂量、核临界性、核爆炸、完整衰变链及复杂产物反应。
未知宏观物性的元素只作假想占位。放射性及衰变热以文字说明。
更详细的参考、限制和操作说明均内嵌于网页问号按钮。
