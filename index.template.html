 HOW THE EXPERIMENT WORKS

接触，只是故事的开始。

01选择与布置点击左侧元素，再点地面放置；点已有方块的面可贴面放置。退出放置后，拖动方块或在右侧输入 X / Y / Z。Y 是方块中心高度，最低 0.5 m。

02启动与观察点击开始。干燥空气会提供 O₂ 与 N₂；湿润空气另有少量水蒸气。氩气或真空适合单独观察元素间的接触。选中方块后可点火 / 加热，形成局部热斑。

03暂停、还原与比较空格播放 / 暂停，F 聚焦，Esc 退出放置，Delete 删除选中方块。还原保留最初布局；保存 / 载入用于离线交换 JSON 布局。

这套模型能解释什么？

覆盖 118 种元素的选择和基础物性，内置 条常见反应路径：卤化、氧化、氮化、氢氧燃烧、硫化与汞齐化。按接触面积、启动温度和剩余原子物质的量限制反应，并在相邻表面间交换热量。使用灰体近似估计界面与产物云的高温辐射散热；有效发射率和散热面积为示意参数。界面反应消耗单质，生成物用表面颜色和右侧文字表示。

块体初始为 25°C 单质：碳用石墨，硫用斜方硫，磷可选白磷 / 红磷。气体按 25°C、1 atm 的初始 1 m³ 估算质量；真空指周围气氛，方块内初始气体仍为此状态，之后会扩散。气体淡色与云团是显示辅助；真实的 H₂、O₂、N₂ 等无色。

哪些结果需要保留判断？

这是规则驱动的教学沙盒，并非全元素反应预测器。无匹配路径会显示“反应库未覆盖”。启动温度、反应速度与局部热容量是示意参数；界面温度不代表整块温度，色彩和粒子不表示实测光谱或浓度。固体的坐标固定；液体铺展、气体高斯扩散为近似。开放空气按持续供给的环境储库处理。

未求解流体力学、压力波、复杂多步反应、产物的后续反应、氧化膜厚度、潜热和完整衰变链；高温也不预测所有解离与电离。烟雾为产物气溶胶的定性效果。辐射无可见光效果；紫色“☢”仅在诊断图层显示。不计算核临界性、核爆炸或剂量，因此一立方米核材料不能据此判断实际表现。短寿命与超重元素只作假想占位，衰变热只作文字批注。
